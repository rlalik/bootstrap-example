# Usage

Can be run in various way:

1. Local root application:
   ```bash
   root webwindow.cxx
   ```

1. Web based root application:
   ```bash
   root --web=chrome webwindow.cxx
   ```

1. Standalone application:
   ```bash
   make
   ./webwindow
   ```

1. Standalone web application:
   ```bash
   make
   ./webwindow --web=chrome
   ```

Instead of chrome you can use your favourite browser.
